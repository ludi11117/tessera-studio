## 用户能直接操作的流程

打开工作室 → 方案与定制 → 学习与训练。

1. 明确比较两份方案，可选最多两项理由：表达清楚、实施负担、细节程度、整体搭配。自由补充的文字只留作记录，不自动抽取训练标签。
2. 点击“本地训练并启用”。本次训练在本机执行，不调用付费API、不上传任务文字。生成与AI修正仍使用原供应商，不能据此宣称整个应用的数据都不出机。
3. 查看真实训练曲线、实际更新参数、模型版本、数据划分与推荐调整。只有模型版本与当前有效反馈一致，才能参与排序；训练不替换正文。
4. 可以调整已经有训练理由的维度侧重，在同一可行集合中重新排序，不额外训练、不放宽硬条件。未标注过的维度保持禁用。
5. 同一个训练版本同时保留语义线性对照，可直接切换。较复杂模型表现较差时，不强迫使用深度网络。
6. 新增或撤回比较后，旧权重停止用于变化后的反馈集合，回退到其他可用推荐方式。用户可重新训练；与当前反馈一致的历史版本可重新启用。撤回训练反馈不修改正文，支持撤回操作恢复。
7. 条件试算可以改变篇幅与逐日覆盖，查看可行组合数量和代表方案。试算不保存条件；用户确认后才写入验收契约，之后仍需另行采用正文。没有实现真实费用、工期或技术正确性的自动核验。

首页“查看本地训练演示”使用开发者编写的文字和8次**模拟选择**，权重与曲线是实际计算结果；它不是真实用户偏好或成品成功案例。普通任务不会继承演示标签。

## 这次实际训练了什么

- 本地冻结编码器采用官方发布的多语MiniLM ONNX量化权重，输出384维语义表示。遵照模型池化配置，执行遮罩均值池化；长文按词元分窗，再做窗口加权均值与归一化。最多64窗，超出时缓存记录截断状态。它是偏好特征，不用于事实核验。
- 网络输入为808维：语义向量、语义与任务向量的乘积、原34维文字特征、6维章节位置。
- 共享偏好网络为 `808 → 32(tanh) → 12(tanh)`；按章节求均值，并计算相邻/首尾章节交互。文档表示24维，输出整份偏好和4项明确理由。
- 每个网络共26,404个参数，使用3个独立初始化；整体比较使用成对逻辑损失，理由作为额外的成对监督，采用Adam更新并约束参数偏离初始值。
- 训练反馈少于4条，只更新输出层；4–7条开放最后隐藏层；8条起开放两层偏好网络。阈值是保守工程选择，尚未证明最优。阈值按实际训练集数量计算，而非包含测试组的总数。
- **冻结语义Transformer，没有微调上游Qwen，也没有训练通用大模型或跨任务个人模型。**
- 有效比较不足15个不同文字对组时，使用全部反馈拟合，不显示测试准确率。达到阈值后按无序文字对分组划分训练/验证/测试，反向或重复比较不会跨组泄漏；验证用于早停，测试不参与梯度或选步数。留出的比较可能复用候选文字，不能等同新措辞泛化测试。
- 已训练网络可用初始化集成的分歧与偏好熵选择下一次完整组合比较；先筛合法方案，最多考察前24个组合。此不确定性未经校准，不是KG/qEUBO方法，也尚未证明能减少用户反馈次数。

官方模型与实现依据：[模型卡](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)、[官方ONNX权重](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2/blob/main/onnx/model_quint8_avx2.onnx)、[ONNX池化说明](https://sbert.net/docs/sentence_transformer/usage/efficiency.html)。本机固定版本为 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`，权重SHA-256为 `98a01d88b7de996cdea58c32ca71208c09968d143798814b2ea09d3439dc334f`；原README及来源清单保存在D盘缓存。

## 对照结果及限制

离线开发评价：3种模拟偏好 × 3种子，每次24条旧措辞比较，另用新措辞与新候选ID测试80对。真值仅用于构造模拟反馈和离线评分，不输入编码器。三种方法使用相同反馈；语义线性和深度模型使用同一语义输入、数据划分和每个模型的步数上限，深度模型额外使用3个初始化，不能称等计算量对照。

| 新措辞方向一致率，跨3种子均值 | 语义线性 | 语义深度 |
|---|---:|---:|
| 偏好具体行动 | 95.4% | 90.4% |
| 偏好温和表达 | 90.0% | 94.2% |
| 偏好章节搭配 | 67.9% | 68.3% |
| 总均值 | 84.4% | 84.3% |

ID基线在新ID上为50%，属于没有跨ID内容迁移的预期；它对原候选的能力不能据此被否定。深度网络没有总体胜过语义线性对照。样本由开发者设计，不能当真实用户收益，也没有完成与直接多轮对话的公平试用比较。

可回放记录：`experiments/runs/deep-semantic-1793107905213400200/report.json`，同目录有9份权重、模型报告、训练/测试输入和预测，以及源码快照。首轮记录 `deep-semantic-1793107795236743300` 也保留；首轮温和场景的理由标签设计不恰当、ID基线仅写理论值，已在第二轮改为不添加该理由并实际计算基线，不能混为完全一致重跑。
