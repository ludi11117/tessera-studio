# 更容易开始，更精确地打磨

Tessera 默认进入精简工作区：从想法、灵感、局部打磨走到核对交付。每一步突出当前下一步；首页高级输入、章节切换和算法面板可通过顶部“完整工作台”展开。切换只保存本机界面偏好，不修改任务或生成偏好标签。验收条件编辑在精简模式中折叠保留。

## 只改选中的文字

在正文选中一句或一段，可选择“更简洁”“补细节”“换个感觉”或“给我两个版本”。先查看选中原文、替换版本和整章预览，明确采用后才更新正文；可以撤回。每次最多一次模型请求，两个版本也在同一请求中生成，没有自动付费重试。失败后需重新选取。

正文排版导致无法唯一定位原文，或选中内容在同章重复时，会转到只读原文框精确选择。移动设备和键盘用户也可从每章“局部调整”打开原文框。当前选择范围为 1–1500 个 Unicode 码点，每个替换版本最多 3000 个字符。

服务端冻结章节、版本、字符起止位置、原文哈希和任务 revision。模型只返回替换字符串，整章由程序执行 `原文前缀 + 替换 + 原文后缀`；模型提供的额外章节不参与修改。字符位置按 Unicode 码点传输，前端将 JavaScript UTF-16 下标转换，避免 emoji 之前的位置错位。

草案逐版检查事实占位符、材料引用、锁定、保留片段和现有机器验收条件。不可行版本可以查看，但不能采用。采用前重新检查 revision、原文哈希和可行性；并发变化会使旧草案只读。正式写入沿用原事务、审计、撤回和核对失效机制，记录选区及选区外前后缀哈希。不需要新增数据库结构或更换语言。

## 验证与实际边界

- 研究环境共 126 项 Python 检查通过，其中新增 6 项覆盖精确范围、重复句子的第二处、emoji、事实和保留片段、锁定、过期版本、撤回、单次失败与模型越界输出。
- `tests/studio-focused.cjs` 从实际默认精简模式验证：界面切换及刷新恢复、正文选择、一次请求两个备选、预览不采用、精确替换、撤回、原文框选取及过期草案禁用。360/390/740/820/1024/1512 六档无横向溢出，16px 保留。
- 既有 smoke、context-trace、drafts 浏览器流程使用完整工作台验证原能力；其他旧浏览器与捕获脚本也明确选择完整模式，默认模式由新检查覆盖。
- 8765 正式与 8766 隔离预览使用原数据库进行只读浏览器核对，业务表指纹前后比较；证据留在本机忽略目录 `docs/validation/`，不进入发布仓库。

浏览器生成测试使用独立模拟供应商，本轮真实付费调用 0 次，没有新训练或正式偏好标签。模拟响应只证明流程与边界，不证明真实模型文案质量、真实用户完成率或节省时间。

“其他原文保留”指渲染前正文字符串的选区外字符不变。更改 Markdown 标记可能影响整章视觉表现；该机制不保证语义正确、事实真实或网页组件样式保持。当前交付仍是文本成果与项目方案，参考网页组件编辑和代码运行尚未实现。
