## 本轮真正新增的便利

1. **模型搜索**：在AI设置明确读取模型列表后，展开“搜索接口返回的模型”。支持不区分大小写的名称子串筛选、空结果说明和长列表截取；点击只填入模型名，保存才生效。筛选不联网；更改接口会清空上一个接口的列表。不提供列表的服务继续允许手动填写。
2. **条件对照**：在“方案与定制 → 并排比较”展开“逐项对照条件”。逐列展示A/B/C实际字符数、改动章数、各项机器条件和当前可采用状态，可直接进入条件设置。未确认的条件明确作为建议规则试检查；通过不代表事实与语义已验证。

条件表格比较的是当前任务的三份候选，不是多家模型的真实质量评测。没有调用promptfoo运行评估，没有获得新的真实用户节省时间数据，没有改变原有深度模型与线性对照的实验结论。
