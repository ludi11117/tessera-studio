05 / WHY IT IS DIFFERENT

和普通对话式生成的差别，在模型之后。

能力普通对话生成拾构的本地程序
并发修改后写覆盖先写revision CAS，旧版本返回 409
局部修改模型重写整段，可能顺手改别处服务端按码点拼接，选区外哈希不变
无解条件让模型“再想想”有限枚举 + 位集过滤 + 冲突核 + 最小修正
偏好与交付没有可复核的边界偏好仅来自明确比较；机器检查与人工确认分开记录
模型调用失败后静默重试冻结输入、调用上限、尝试记录，失败不伪装成功

代码位置

  • store.py事务、revision、事件快照、训练标签边界
  • ai/decision.py枚举、位集约束、前沿、冲突核、敏感度
  • ai/local_revision.py码点选区、前后缀哈希、过期拒绝
  • ai/service.py作业生命周期、幂等、冻结配置、上限
  • proof.py本页的隔离沙盒与实时证据

边界，写在能力旁边

  • 候选搜索是 3⁴ 的有限穷举，不是通用 SAT/ILP 求解器。
  • 冲突核是删除式局部结果，不保证条件数最少，也不代表只有一处冲突。
  • 偏好分是任务内模型的相对估计，不等于内容质量或真实用户收益。
  • 链路校验证明本地快照一致，不提供密码学防篡改或跨节点共识。
  • 真实 API 验收仍有内容失败记录；通过机器条件不等于可以不经人工核对直接交付。
