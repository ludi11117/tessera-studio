# Tessera · 拾构

**把喜欢的，拼成你的。**

一个面向不会写 Prompt 的人的本地 AI 创作工作室。从模糊想法出发，看具体方向、留下满意的局部，再把需求逐项落实到成果。

## 四步做出自己的版本

1. **说想法**：用简单语言描述目标，按项目类型整理需求卡。
2. **找灵感**：结合本次回答与素材探索方向，查看示例、取舍和原文依据。
3. **留细节**：混搭章节、保留局部原文，修改先预览，再明确采用。
4. **成作品**：逐项关联需求与正文、标记缺口，导出正文和可追溯的交付包。

默认精简工作区突出下一步，顶部可展开完整工作台。选中文字可局部调整，一次请求查看两个备选，明确采用后只替换选区，支持撤回。

当前交付文本成果和项目方案。网页组件编辑、代码执行和网站部署尚未实现。

## 本地运行

需要 Python 3.11+。基础功能使用标准库，无需安装第三方包：

```powershell
python -B server.py --port 8765
```

打开 http://127.0.0.1:8765/ 。Windows 也可双击 **启动拾构.cmd**。AI设置支持兼容 Chat Completions 的接口；填写自己的地址、模型和 Key。保存配置不发送生成请求。

默认业务数据在项目 `data/`，不会提交到版本库。Windows凭证使用当前用户DPAPI加密。建议将项目、模型缓存和临时目录放在空间充足的磁盘；本项目开发环境使用D盘。

## 能力与算法

- 任务内明确偏好学习，保留线性对照与可选深度模型。
- 有限候选组合的精确搜索、硬条件、前沿、冲突核与最小调整集合。
- 章节×版本定制画布、篇幅×改动量地图。
- 单次预算的上下文灵感作业、冻结输入与供应商配置。
- 内容快照绑定的需求核对，按需复用冻结多语编码器查找语义线索。
- 版本检查、事务审计、修改草案、撤回与带证据的ZIP。

可选研究环境见 `setup-research.ps1`；语义模型由 `scripts/setup_semantic_encoder.py` 单独准备，模型文件不包含在仓库中。部分浏览器验证脚本沿用开发机D盘依赖路径，其他环境需调整。

## 验证与边界

开发环境126项Python检查通过，四步流程、上下文灵感、需求核对、局部改写、保留与导出已用隔离模拟供应商验证。本地语义查找使用实际ONNX编码器。

模拟验证不能证明真实模型成品质量或用户时间收益。字面和语义定位都只提供核对线索；明确的机器规则与用户确认分别记录。深度模型没有在所有既有实验中胜过线性对照，不宣称全面更优。

```powershell
python -B -m unittest discover -s tests -q
```
